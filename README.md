# MGC Languages — Company Pilot v6.0.18

Корпоративный языковой сервис для сотрудников автопрома: **китайский (путунхуа / Standard Mandarin) + английский**, профессиональная терминология, реальные рабочие сценарии и интерактивная тренировка коммуникации.

**Текущий статус:** v6.0.18 Company Pilot на `main`. Релиз сохраняет UX hardening v6.0.17 и добавляет крупное расширение словаря, точный паритет китайского/английского контента и Automotive Arcade из 20 различных игровых механик.

## Что нового в v6.0.18

### Равный объём китайского и английского словаря

До расширения базовый корпус содержал **1735 китайских** и **256 английских** терминов. Для v6.0.18 автоматически сформирован параллельный английский слой из **1479** профессиональных переводов, поэтому основной двуязычный корпус теперь имеет одинаковый размер.

Дополнительно в оба языка добавлено по **240 новых автомобильных терминов**:

- **Окраска — 80** терминов на китайском и те же 80 понятий на английском;
- **Логистика — 80** терминов на китайском и английском;
- **Кузов и компоненты — 80** терминов на китайском и английском.

После этого к обоим языкам одинаково добавляется общий корпоративный слой `experience.extra_terms`, поэтому **итоговое количество терминов в runtime остаётся строго одинаковым для Chinese и English**. Паритет проверяется автоматически в CI и в реальном Docker/LAN runtime.

Сгенерированные данные находятся в:

```text
data/shop_expansion_v618.json
data/english_parallel_v618.json
data/v618_content_manifest.json
mgc/content_v618.py
```

### Automotive Arcade — 20 игр

Раздел «Игры» переработан из небольшой подборки упражнений в отдельную автомобильную аркаду. Сейчас доступны **20 разных механик**, а не один тест с разными названиями:

1. Word Match — термин ↔ перевод.
2. Listening Sprint — распознавание термина на слух.
3. Precision Check — выбор единственного точного значения.
4. Phrase Builder — сборка рабочей фразы.
5. **Car Part Hotspot — интерактивная схема автомобиля: нужно нажать на правильную деталь.**
6. Build the Car — технологическая последовательность производства.
7. Factory Router — отправить термин в правильный цех.
8. Tool Selector — выбрать инструмент под задачу.
9. Defect Detective — определить производственный дефект.
10. Safety Spot — найти опасность на рабочем месте.
11. Quality Gate — принять решение PASS / REWORK / HOLD.
12. Logistics Flow — собрать правильный материальный поток.
13. Kanban Challenge — принять решение о пополнении.
14. Build the BOM — связать компонент с подсистемой.
15. Spec or NOK? — сравнить факт с допуском.
16. 10-Second Recall — быстрый ответ под таймер.
17. Memory Garage — игра на пары и память.
18. Odd One Out — найти термин из другой группы.
19. Dialogue Duel — выбрать профессиональную реплику.
20. Shift Incident — принять решение в реальной сменной ситуации.

Игры используют автомобильный словарь, производственные процессы, качество, логистику, безопасность и рабочую коммуникацию. Игровая сессия по-прежнему ограничена **5 ответами** на backend-уровне: это сохраняет короткий темп и не позволяет фармить XP бесконечными сериями.

Основные файлы:


## UX hardening от 08.09.2026

Слой v6.0.17 сохранён в v6.0.18 без отката:

- декоративные цитаты, hero-сообщения и второстепенные слоганы скрыты из пользовательского интерфейса;
- для китайских упражнений добавлен Pinyin fallback для основных автомобильных терминов, включая `整车装配 → zhěng chē zhuāng pèi`;
- игровые упражнения, которые могут использоваться для XP-фарма, ограничены **5 ответами за одну игровую сессию** на backend-уровне;
- профессиональные темы используют локальные/offline тематические SVG-иллюстрации: сборка, сварка, окраска, штамповка, качество и логистика;
- hero-иллюстрации очищены от лишних декоративных фигур;
- озвучка сначала выбирает более естественные браузерные голоса с приоритетом **Natural / Neural / Online / Premium** и подходящие Mandarin/English voice-профили; старый механизм остаётся fallback, если качественного голоса на устройстве нет.

## One-click запуск Company Pilot

### Windows

Дважды запустите:

```text
START_COMPANY_PILOT.bat
```

Launcher использует `scripts/start_company_pilot.ps1`, выполняет корпоративный preflight, собирает `docker-compose.pilot.yml`, запускает сервис, проверяет readiness и открывает приложение после успешного старта.

Основной шаблон настроек:

```text
.env.company-pilot.example
```

Для controlled company pilot должны быть настроены корпоративные OIDC/SSO, PostgreSQL, secure cookies и остальные обязательные параметры из шаблона и runbook.

## Проверка перед запуском

Ключевой preflight:

```bash
python scripts/company_pilot_preflight.py --strict-corporate
```

Финальный запуск на инфраструктуре компании всё равно требует IT/UAT-проверки и отсутствия открытых S1/S2 дефектов.

## Китайский: что именно изучает пользователь

Основной курс учит **путунхуа (普通话) — Standard Mandarin**. Информация о диалектах и региональном произношении используется как справочный материал и не подменяет основной стандарт обучения.

Поддерживаются пиньинь, тоны, воспроизведение произношения и пояснения по китайскому языку. Микрофон и запись голоса не являются обязательной частью пилотного учебного контура.

## Корпоративная безопасность

Company Pilot рассчитан на controlled deployment. Для корпоративного режима предусмотрены, в частности:

- `AUTH_MODE=oidc`;
- отключённая самостоятельная регистрация;
- secure cookies;
- readiness-проверки OIDC, RLS и governance;
- PostgreSQL вместо SQLite для корпоративного контура;
- разграничение ролей;
- аудит и governance терминологии.

Факт успешного запуска приложения не заменяет финальную приёмку IT/Security. На инфраструктуре компании отдельно проверяются TLS/reverse proxy, OIDC, PostgreSQL, backup/recovery, мониторинг и корпоративные политики доступа.
