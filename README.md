# MGC Languages — Company Pilot v6.0.17

Корпоративный языковой сервис для сотрудников автопрома: **китайский (путунхуа / Standard Mandarin) + английский**, профессиональная терминология, реальные рабочие сценарии и тренировка коммуникации.

**Текущая пилотная версия: v6.0.17 Company Pilot Candidate.**

## Что входит в пилот

- единая главная страница с выбором китайского и английского направления;
- китайский язык для автопрома с пиньинем, тонами, произношением и разделом **«Информация о китайском»**;
- английский язык для автомобильной промышленности;
- автомобильная и производственная терминология;
- реальные рабочие ситуации, сценарии и практические задания;
- обучение, тесты, повторение/SRS, игры и оценка прогресса;
- **«Фраза дня»**, **«План на сегодня»**, **«Быстрый доступ»** и **«Подборка терминов»**;
- роли User / Manager / Editor / Admin и управляемый корпоративный контент;
- аналитика обучения и пилотные operational controls;
- корпоративная аутентификация OIDC/SSO, secure-cookie и readiness policies;
- PostgreSQL как корпоративное хранилище, Alembic migrations и RLS-контроль;
- Docker-развёртывание и one-click запуск Company Pilot на Windows.

### Главная страница

В актуальном пилоте текст карточки зафиксирован в корректной форме:

## One-click запуск Company Pilot

### Windows

Дважды запустите:

```text
START_COMPANY_PILOT.bat
```

Launcher использует `scripts/start_company_pilot.ps1`, выполняет корпоративный preflight, собирает `docker-compose.pilot.yml`, запускает сервис, проверяет readiness и открывает приложение после успешного старта.

Основной шаблон настроек:

```text
.env.company-pilot.example
```

Для controlled company pilot должны быть настроены корпоративные OIDC/SSO, PostgreSQL, secure cookies и остальные обязательные параметры из шаблона и runbook.

## Проверка перед запуском

Ключевой preflight:

```bash
python scripts/company_pilot_preflight.py --strict-corporate
```

Дополнительно пилот содержит отдельные тесты v6.0.17, UAT и GO/NO-GO документацию.

## Китайский: что именно изучает пользователь

Основной курс учит **путунхуа (普通话) — Standard Mandarin**. Информация о диалектах и региональном произношении используется как справочный материал и не подменяет основной стандарт обучения.

Поддерживаются пиньинь, тоны, воспроизведение произношения и пояснения по китайскому языку. Микрофон и запись голоса не являются обязательной частью пилотного учебного контура.

## Корпоративная безопасность

Company Pilot рассчитан на controlled deployment. Для корпоративного режима предусмотрены, в частности:

- `AUTH_MODE=oidc`;
- отключённая самостоятельная регистрация;
- secure cookies;
- readiness-проверки OIDC, RLS и governance;
- PostgreSQL вместо SQLite для корпоративного контура;
- разграничение ролей;
- аудит и governance терминологии.

Факт успешного запуска приложения не заменяет финальную приёмку IT/Security. На инфраструктуре компании отдельно проверяются TLS/reverse proxy, OIDC, PostgreSQL, backup/recovery, мониторинг и корпоративные политики доступа.

## Локальная разработка

Для локальной разработки сохранён обычный Docker-путь:

```bash
docker compose up --build
```

Локальный профиль не следует использовать как корпоративную production-конфигурацию.
