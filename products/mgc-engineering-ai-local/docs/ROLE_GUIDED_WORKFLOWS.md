# Role Guided Workflows — v6.0.7

Role is a UI focus, never an authorization grant.

## Engineering
- Change review: Change Impact -> V&V/evidence -> Release decision.
- Part release: Part 360 -> BOM/drawing -> Configuration/baseline.
- Engineering problem: Digital Thread -> historical analogues -> Decision Record.

## Manufacturing Engineering
- Buildability: EBOM/MBOM -> Process/WI -> Handover gate.
- Cut-in: Effectivity -> stock disposition -> MES/next build.
- Launch blocker: Program blocker -> owner evidence -> human gate review.

## Quality
- Defect investigation: VIN/genealogy -> PFMEA/Control Plan -> 8D/containment.
- Suspect population: part/supplier lot -> VIN population -> containment.
- Effectiveness: before/after -> recurrence -> Lesson Learned.

## Supplier / Localization
- Incoming quality -> Supplier 8D -> PPAP/effectiveness.
- Part/supplier -> localization evidence -> release readiness.

## Program / Launch
- Critical chain -> top blockers -> decision review.
- Milestone -> what-if -> downstream gates.

## Field Reliability
- Exposure -> VIN trace -> DFMEA/validation.
- Revision comparison -> field recurrence -> human effectiveness review.

## Leadership
- Critical actions -> Decision Queue -> evidence/owners.
- Domain health -> next gate -> cross-domain workflows.
