# Golden Automotive Dataset — v6.0.6

`pilot/golden_dataset_v1.json` is a deterministic synthetic UAT fixture. It contains no real customer, employee or vehicle data.

Current fixture: 60 synthetic parts, 59 BOM edges, 24 synthetic VIN-like identifiers and 3 known defect records. Expected assertions are embedded so test outcomes can be reproduced across installations.

Use it for onboarding, smoke testing, regression demonstrations and UAT rehearsal. Never use its result as evidence for production GO.
