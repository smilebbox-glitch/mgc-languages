# Controlled Automotive Pilot Rollout — v6.1.0

Recommended population: **15–30 engineers**, deliberately small enough for governed UAT and large enough to cover cross-domain workflows.

## Week 0 — technical acceptance
Build/runtime, CVE/dependency, OIDC/mTLS, least-privilege DB, backup/restore, target-host performance, observability and operations rehearsal evidence. No real pilot users yet.

## Week 1 — onboarding
3–5 champions: R&D, Manufacturing Engineering, Quality. Synthetic golden dataset and approved non-sensitive project data. Confirm support/escalation path.

## Weeks 2–3 — controlled workflows
Expand to 10–15 users. Run Change Impact/BOM, buildability/change-cut-in, VIN/defect/containment scenarios. Track aggregate UX outcomes only.

## Weeks 4–5 — full pilot cohort
Expand to 15–30 users if blockers remain below pilot thresholds. Add supplier/program/field roles only where required.

## Week 6 — evidence review
Run v6.0.6 UAT evaluation, v6.0.7 feedback closure and v6.0.9 operations acceptance. Corporate Go-Live board decides next step.

No MGC status automatically authorizes production.
