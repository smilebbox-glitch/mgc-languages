# MGC Engineering AI Local v3.8.0 — Engineering Change Management

## Главное

v3.8 превращает существующий Change Impact в управляемый инженерный процесс ECR/ECO.

### Новый процесс

1. Инженер создаёт ECR: деталь, исходная/целевая ревизия, причина, приоритет.
2. Сервис выполняет impact analysis по Revision Compare, BOM, связанным документам и открытым замечаниям.
3. Все использованные документы фиксируются по SHA-256. Если доказательная база меняется до выпуска ECO, финальное согласование блокируется и impact analysis требуется повторить.
4. Автор отправляет изменение на согласование.
5. Другой инженер выполняет technical review. Автор не может согласовать собственное изменение.
6. Engineering Admin выполняет final approval и выпускает уникальный ECO code.
7. Исполнитель фиксирует план внедрения и verification plan.
8. После проверки результат фиксируется, ECO получает статус Implemented.

### Governance

- High/Critical изменения требуют approved Design Review перед выпуском ECO.
- ECR/ECO доступны только пользователям engineer-only контура.
- Каждый change event включён в append-only SHA-256 chain с отдельным head/count anchor.
- События ECR/ECO также записываются в историю затронутых документов.
- Part 360 показывает изменения, относящиеся к детали.

### UI

Добавлен простой раздел **«Изменения»**:

- `+ Создать ECR`;
- пошаговый индикатор ECR → Влияние → Согласование → ECO → Внедрение;
- risk score;
- список затронутых деталей/сборок;
- approvals;
- tamper-evident timeline.

## Совместимость

Upgrade с v3.4–v3.7 выполняется additive/idempotent migration. Существующие таблицы и документы не удаляются.
