DOCKLE NOTE
===========
The repository includes Dockle-compatible static hardening and `make dockle`, but the
packaging environment has no Docker daemon/CLI or Dockle binary. A real image-layer
scan must be executed on the connected corporate Docker build host after images are built:

  docker compose build
  make dockle
  make acceptance

Do not treat this static report as a substitute for the real image scan.
