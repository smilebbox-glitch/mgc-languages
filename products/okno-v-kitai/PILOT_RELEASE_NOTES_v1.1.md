# Окно в Китай — Pilot v1.1

## Новое для пользователя
- раздел «Перед поездкой» получил модуль CNY/RUB;
- официальный курс ЦБ РФ с датой действия и источником;
- быстрые расчёты 100 CNY → RUB и 1 RUB → CNY;
- двусторонний конвертер произвольной суммы;
- наличные курсы покупки/продажи CNY по банкам;
- переключатель Калуга / Москва;
- явное состояние live/fallback и время получения данных.

## Pilot hardening
- `/api/health` и `/api/ready`;
- server-side proxy для валютных источников: браузер сотрудников не обращается к ним напрямую;
- timeout внешних запросов 4.5 с и серверный кэш 15 минут;
- graceful degradation: недоступность валютных источников не роняет сайт;
- Docker non-root + read-only + tmpfs;
- `no-new-privileges`, `cap_drop: ALL`, PID/CPU/RAM limits;
- лог-ротация Docker;
- security headers;
- версия приложения через `APP_VERSION`.

## Граница пилота
- банковские курсы — справочная внешняя информация, не корпоративная финансовая котировка;
- для production рекомендуется согласовать корпоративный источник/лицензию на банковские данные;
- SSO/RBAC, централизованные логи, reverse proxy TLS и корпоративный DNS должны подключаться по стандартам IT компании.
